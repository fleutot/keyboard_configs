# keyboard_configs
Config files for kmonad

arrows.kbd is taken from [kmonad-contrib](https://github.com/kmonad/kmonad-contrib/tree/master/keymaps/iTzHard).

Make sure you are in the groups `uinput` and `input`.
If the compose sequences do not work, such as for international characters, increase the sleep time before calling to setxkbmap in the keyboard config file.
